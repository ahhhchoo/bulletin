Flow

    What I decided, and what’s still open

    • Apple skips the phone screens. Apple already verified them, so they go straight to the name screen, where the name Apple shares is filled in (they can edit it).
    • Usernames: lowercase letters, numbers and underscores only, 3 to 20 characters, no spaces or symbols. Anything else is blocked as you type. Taken names show a red message with three free suggestions. Try “maya”, “sam” or “alina”.
    • Name comes before username. It’s the easy question, so people ease in, and the username screen can offer name-based suggestions later. The name stays private and is only collected for the back end.
    • Open: is the name required? needs a call Right now both fields are required. Asking for a name people can skip lowers drop-off, but then you may not have it later.
    • Open: age limit. needs a call I set 13 as the minimum (the US legal floor). Under 13 is blocked with a message. Worth checking with whoever does your legal.
    • Open: photo is skippable. needs a call Skipping gives a letter avatar from the username. Say if it should be required.
    • Open: Apple accounts and phone. needs a call Apple sign-ups never give a phone number, so you can’t text them or recover the account by phone. You might want to ask for one later.
    • Code screen: six digits, auto-checks on the last digit, a wrong code shakes. In this prototype any code works except 000000. Resend is available after 30 seconds.
